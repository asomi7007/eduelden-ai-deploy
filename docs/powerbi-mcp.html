스크립트를 먼저 다운로드한 후 실행하세요.

수동 설치 (자동 설치 실패 시)

VS Code 수동 설치
https://code.visualstudio.com/download 에서 Windows 64bit 버전을 다운로드하여 설치합니다.
Cline 확장 수동 설치
VS Code 실행 → 왼쪽 Extensions 아이콘 클릭 → "Cline" 검색 → Install 클릭
Node.js 22 수동 설치
https://nodejs.org/en/download 에서 22 LTS 버전을 다운로드하여 설치합니다.
설치 후 터미널에서 node -v를 입력하여 v22 이상인지 확인합니다.
Power BI Desktop 수동 설치
방법 1: Microsoft Store에서 "Power BI Desktop" 검색하여 설치
방법 2: https://aka.ms/pbidesktopstore
방법 3: 터미널에서 winget install Microsoft.PowerBI
MCP 서버 수동 구성
Cline 사이드바 → MCP Servers 탭 → 각 서버 추가:
{ "mcpServers": { "powerbi": { "command": "npx", "args": ["-y", "@anthropic/mcp-server-powerbi"] }, "playwright": { "command": "npx", "args": ["-y", "@anthropic/mcp-server-playwright"] }, "filesystem": { "command": "npx", "args": ["-y", "@anthropic/mcp-server-filesystem", "C:\\Users\\사용자\\Desktop"] } } }

문제 해결

Power BI Desktop 설치 실패
Microsoft Store 접근이 안 되면: winget install Microsoft.PowerBI
Node.js 버전이 22 미만
기존 버전 삭제 후 다시 설치: winget install OpenJS.NodeJS.LTS
MCP 서버가 Cline에서 안 보임
VS Code를 완전히 종료(Ctrl+Shift+P → "Close Window") 후 다시 열어주세요.
Cline 사이드바 > MCP Servers 탭에서 3개 서버가 보여야 합니다.
API 연결 테스트 실패
APIM이 아직 배포 중일 수 있습니다. 당일 강사가 확인해 드립니다.
스크립트 실행이 차단됨
PowerShell에서 먼저 실행: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
