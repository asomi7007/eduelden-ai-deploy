자동 설치 항목

  1. VS Code — 코드 에디터 + AI 에이전트 실행 환경
  2. Cline 확장 — VS Code에서 AI 에이전트 구동
  3. Node.js 22+ — MCP 서버 실행에 필요
  4. Power BI Desktop — 대시보드 제작 도구
  5. MCP 서버 3종
    • Power BI MCP — AI가 Power BI를 직접 제어
    • Playwright MCP — AI가 웹 브라우저를 자동화
    • Filesystem MCP — AI가 실습 파일에 접근
  6. API 연결 설정 — APIM 게이트웨이 + AI 모델 연동
  7. 실습 파일 — 바탕화면에 실습파일.pbix 다운로드
  8. 연결 테스트 — AI 응답 확인

수동 설치 (자동 설치가 안 될 경우)

자동 설치가 되지 않는 경우, 아래 소프트웨어를 직접 설치해 주세요:

  • VS Code 다운로드
  • Node.js 22 LTS 다운로드
  • Power BI Desktop (Microsoft Store)
  • VS Code에서 Cline 확장 설치: Extensions > "Cline" 검색 > Install

당일 준비물 체크리스트

  • 노트북 (Windows 10/11, 64bit)
  • VS Code 설치 완료
  • Cline 확장 설치 완료
  • Node.js 22+ 설치 완료 (터미널에서 node -v 확인)
  • Power BI Desktop 설치 완료
  • 실습파일.pbix 바탕화면에 다운로드 완료
  • 인터넷 연결 가능

문제 해결

Power BI Desktop 설치 오류
Microsoft Store 접근이 안 되는 경우, winget을 사용하세요:
winget install Microsoft.PowerBI
Node.js 버전이 22 미만
기존 Node.js를 삭제 후 22 LTS를 설치하거나:
winget install OpenJS.NodeJS.LTS
MCP 서버가 Cline에서 안 보임
VS Code를 완전히 종료 후 다시 열어 주세요.
Cline 사이드바 > MCP Servers 탭에서 3개 서버가 보여야 합니다.
API 연결 테스트 실패
APIM이 아직 배포 중일 수 있습니다. 당일 강사가 확인해 드립니다.
스크립트 다운로드 실습 파일 다운로드
