2

3

방법 2: 수동 설치 (자동 설치가 안 될 경우)

1. VS Code 다운로드 → Windows 64bit 설치
2. VS Code 실행 → Extensions → "Cline" 검색 → Install
3. Node.js 22 LTS 다운로드 → 설치 (터미널에서 node -v로 확인)
4. Power BI Desktop → Microsoft Store에서 설치 또는 winget install Microsoft.PowerBI
5. Cline 사이드바 → 설정 → API Provider: "OpenAI Compatible"
   Base URL: https://apim-eduelden-ai.azure-api.net/openai/v1
   API Key: 위에 안내된 키 입력
   Model ID: gpt-54-mini
6. Cline → MCP Servers → 아래 3개 추가:
powerbi: npx -y powerbi-mcp
playwright: npx -y @playwright/mcp@latest
filesystem: npx -y @modelcontextprotocol/server-filesystem [바탕화면 경로]
